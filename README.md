# Classroom Interactive Whiteboard

An interactive, browser-based whiteboard designed for classroom instruction, vocabulary practice, and real-time student engagement.

## Features

* **Interactive Canvas:** Draw, select, highlight, and add custom sticky notes or visual markers.
* **Text Formatting:** Double-click anywhere on the board to insert text cleanly with instant editing.
* **Color & Brush Controls:** Palette picking, hex color customization, and responsive brush sizing.
* **Game Mode:** Auto-extracts vocabulary directly from whiteboard text to generate interactive word games (e.g., Hangman).
* **AI Assistance:** Built-in contextual tools for real-time text translations, grammar feedback, phrase examples, and dialogue generation.
* **Image Support:** Paste images directly onto the canvas from your clipboard or drag-and-drop.
* **Export Options:** Download board captures directly as `.png` files auto-stamped with the current date.

## Hotkeys & Shortcuts

* `Ctrl + L`: Activate Drawing Mode
* `Ctrl + S`: Activate Selection / Pointer Mode
* `Ctrl + Z`: Undo last action
* `Delete`: Remove selected items
* `Double Click`: Insert new text box

## Tech Stack

* **Front-end:** HTML5, CSS3, Vanilla JavaScript
* **Canvas Engine:** Fabric.js
* **Icons:** Font Awesome
